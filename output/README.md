# Output Directory

This directory is the designated output destination for benchmark runs, profiling artifacts, and simulation outputs (e.g. from `notebooks/player_simulator.py` or `scripts/`).

Artifacts generated into this directory are ephemeral and gitignored. Do not place project source files or manual technical specifications in this folder. For cloud cost and network benchmarks, refer to [`../docs/NETWORK_BENCHMARK_FIREBASE_COST_ESTIMATION.md`](../docs/NETWORK_BENCHMARK_FIREBASE_COST_ESTIMATION.md).
